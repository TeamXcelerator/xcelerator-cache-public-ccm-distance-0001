# Xcelerator Cache: CCM distance

Target-independent CCM eigenfunction profiles and inter-discretization distance
measurements.

Artifacts and metadata in this repository are generated by the
[Xcelerator Toolkit](https://github.com/TeamXcelerator/xcelerator-toolkit).

## Cache family

**CCM distance**

This public shard accepts only CCM artifacts whose construction does not use a
runtime target definition.

Artifact kinds assigned to this family:

- `ccm_discretization_distance`
- `ccm_eigenfunction_profile`

## Layout

```text
objects/sha256/<first-two-hex>/<full-sha256>
artifacts/<artifact-kind>/<logical-key>/<parameter-digest>/
```

Object payloads are immutable and content-addressed. Artifact manifests provide
logical identity, provenance, validation state, and ordered object references.
The Xcelerator cache registry is the authority for shard routing.

## Measurement conventions

A `ccm_eigenfunction_profile` retains the normalized `V_n`
coefficients. These are lossless, so the eigenfunction can be evaluated at any
abscissa and any integration rule applied at any resolution, without repeating
the spectral solve that produced it.

A `ccm_discretization_distance` records the weighted distance between two mode
cutoffs at fixed spectral parameter. The cutoff pair is canonicalized because
the distance is symmetric. Each result retains the integration rule, grid
variable, resolution, weight exponent, and working precision that produced it.

Target-derived distance, resolution, residual, and deviation artifacts are
private-only in Xcelerator Toolkit v0.14.1. They are deliberately excluded from
this repository's routing metadata and publication history.

Eigenvalue brackets carry their own certification state. Eigenfunctions and
distances derived from them are high-precision numerical approximations.
Finite computations are reported with their finite scope; they are not
presented as proofs of infinite-dimensional conjectures.
