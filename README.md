## Cache family

**CCM target distance**

Normalized CCM eigenfunction profiles and weighted target-distance measurements.

Artifact kinds assigned to this family:

- `ccm_eigenfunction_profile`
- `ccm_target_distance`

## Layout

```text
objects/sha256/<first-two-hex>/<full-sha256>
artifacts/<artifact-kind>/<logical-key>/<parameter-digest>/
```

Object payloads are immutable and content-addressed. Artifact manifests provide
logical identity, provenance, validation state, and ordered object references.
The Xcelerator cache registry is the authority for shard routing.

## Measurement conventions

A target distance has no meaning apart from the convention that produced it. A
`ccm_target_distance` artifact therefore records, for every integration rule it
was evaluated under, the rule family, the rule, the grid variable, and the
resolution, alongside the weight exponent `alpha` and the working precision.
Several rules are retained together so that the spread between them is visible
rather than having to be reconstructed. That spread bounds convention
sensitivity; it is not a convergence estimate.

A `ccm_eigenfunction_profile` additionally retains the normalized `V_n`
coefficients. These are lossless, so the eigenfunction can be evaluated at any
abscissa and any integration rule applied at any resolution, without repeating
the spectral solve that produced it.

Eigenvalue brackets carry their own certification state. The eigenfunctions and
the distances derived from them are high-precision numerical approximations.
Finite computations are reported with their finite scope; they are not
presented as proofs of infinite-dimensional conjectures.
